# 정리 작업의 검증 기록

후속 핵심 훅 분리와 55개 테스트·응답 경합 검사는 [2026-11-01 기록](PLANNER_REFACTOR.md)을 참고하세요. 아래는 최초 정리 당시의 보존 기록입니다.

2026-10-31 기준입니다. 기능 개선이나 성능 향상 수치가 아니라, 저장소를 정리하면서 기존 동작을 보존했는지 확인한 기록입니다.

## 변경 범위

- 루트·프론트·백엔드 안내와 직무별 코드 탐색 경로를 정리했습니다.
- 큰 훅의 독립 함수 33개를 항공 변환·취향·코드 매핑·로컬 저장·편집 초안의 5개 모듈로 옮겼습니다.
- React 상태/effect/요청 처리 순서와 화면 props를 유지했습니다. 초안 복원 함수에는 기존에 참조하던 날짜 값을 명시적으로 전달했습니다.
- App·일정 결과 화면·생성 API·백엔드 생성/Worker에 책임과 읽는 순서 주석을 추가했습니다.
- CSS는 주석만 추가하고 규칙과 적용 순서를 유지했습니다.
- `.cjs` 테스트를 기본 실행에 포함했습니다. 과거 AWS 배포 파이프라인은 비활성 참고본으로 보존하고 새 CI는 검사만 수행합니다.

GitHub 검사는 소스 정리 커밋 `e66cfc1`에서 실행했습니다. 이후 변경은 이 검증 기록과 과거 문서의 빈 줄 정리뿐이며, 실행 코드를 다시 바꾸지 않았습니다.

추가 계약 검사는 항공 표시가와 저장가, 취향 정규화, 과거 초안 초기화, 저장소 차단 시 예외 처리를 확인합니다. [테스트 코드](../frontend/tests/plannerContracts.test.mjs)

## 확인 범위의 한계

실습용 AWS는 종료된 상태이므로 실제 Bedrock·SQS·운영 DB와의 전체 연결은 재실행하지 않았습니다. 지도 키를 요구하는 실제 지도·인증 전체 흐름과 운영 전용 `build:release`도 이번 검증에 포함하지 않았습니다. 일반 빌드의 큰 청크 경고는 정리 전후 모두 존재하며 이번 정리에서 숨기거나 임계값을 변경하지 않았습니다.

검증은 회귀 가능성을 줄이는 근거이며 모든 환경에서 오류가 없다는 보증은 아닙니다. 원래 공개본과 분리된 작업 브랜치에서 검증했습니다.
