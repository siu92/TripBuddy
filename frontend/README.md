# 얼마길 — AI 여행 플랫폼

국내·해외 여행을 설계할 수 있는 React + Vite 여행 플랫폼입니다. 제주도 2박 3일은 발표용 시연 시나리오이며, 항공·숙소 선택에 따라 여행 예산과 일정을 다시 계산합니다.

## 발표 흐름

1. 국내 또는 해외에서 여행지를 고르고, 국내 여행지 중 제주도를 선택합니다.
2. 김포 또는 인천에서 제주로 가는 왕복 항공편 10개를 비교해 하나 선택합니다.
3. 가격대를 먼저 고른 뒤 제주공항·애월·협재·성산·중문 권역의 숙소를 비교합니다.
4. 인원과 숙박일수에 맞춰 총 경비를 즉시 확인합니다.
5. 일정 생성 후 DAY 1~3 탭을 눌러 날짜별 제주 동선을 확인합니다.

## 시연 데이터 기준

- 항공편은 대한항공·아시아나항공·제주항공·진에어·티웨이항공·에어부산·이스타항공의 국내선 노선을 참고한 **발표용 왕복 견적**입니다. 실제 운항 시간과 운임은 각 항공사 예약 페이지에서 달라질 수 있습니다.
- 숙소는 메종 글래드 제주, 마레보 비치 호텔, 플레이스 캠프 제주 등 실제 운영 중인 숙소를 권역별로 배치했습니다. 10~20만원대 1박 견적은 발표용 추정치입니다.
- 일정에는 이춘옥 원조고등어쌈밥, 한담해안산책로, 협재해수욕장, 오설록 티 뮤지엄, 새별오름, 동문시장 등 실제 제주 스폿을 반영했습니다.

## 친구에게 전달하는 방법

이 폴더를 압축해서 친구에게 전달하면 됩니다. 친구는 `src` 폴더와 `package.json`, `index.html`을 자신의 `C:\Front-end\frontend`에 덮어넣으면 됩니다. 기존 `vite.config.js`는 그대로 둬도 됩니다.

## 백엔드 연결 준비

- API 호출 파일: `src/api/tripPlanApi.js`
- 기본 주소: `http://localhost:8080`
- 실제 서버 주소가 달라지면 `.env` 파일에 `VITE_API_BASE_URL=http://서버주소`를 추가합니다.
- 현재는 화면 시연이 바로 되도록 모의 모드입니다. 실제 연결 시 `.env`에 `VITE_USE_MOCK=false`를 추가합니다.
- 기본 호출 주소는 `POST /api/v1/trips/plans`입니다. 친구분의 Swagger 명세에 맞춰 이 주소와 요청 항목만 변경하면 됩니다.

## 실제 네이버 지도 연결

프로젝트 최상단에 `.env` 파일을 만들고 아래처럼 네이버 지도 클라이언트 ID를 넣으면, 결과 화면의 지도 영역에 실제 네이버 지도와 경로 점이 표시됩니다.

```text
VITE_NAVER_MAP_CLIENT_ID=발급받은_클라이언트_ID
```

지도 키가 아직 없을 때에도 화면은 정상으로 보이며, 지도 연결 준비 화면이 대신 표시됩니다.
